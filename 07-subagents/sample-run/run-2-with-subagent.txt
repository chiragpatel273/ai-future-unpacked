# Bug Report

**1) Coupon SAVE10 gives no discount when a sale item is in the cart**
- File: `shop/rules.py`
- Function: `percent_off`
- Line 4: `if any(i.on_sale for i in items):` (followed by `return 0.0`)
- Cause: The percent rule bails out and returns 0 whenever *any* item in the cart is on sale, voiding the entire coupon instead of just excluding the sale item from the discount. Flat-amount coupons (`amount_off`) aren't affected, which is why it's specific to a percent coupon like SAVE10.

**2) US order of exactly $50.00 still pays shipping**
- File: `shop/shipping.py`
- Function: `shipping_cost`
- Line 14: `if free_over is not None and amount > free_over:`
- Cause: Strict `>` instead of `>=`. `50.00 > 50` is False, so the rate isn't set to free; "free from $50" should include exactly $50.

**3) Order email for 3 mugs shows 12.00 instead of 36.00**
- File: `shop/emails.py`
- Function: `order_confirmation`
- Line 15: `lines = "\n".join(f"  {i.qty} x {i.name}  ${i.price:.2f}" for i in order.items)`
- Cause: The line prints the per-unit `i.price` (12.00) rather than the line total; it should use the quantity-multiplied total (3 × 12.00 = 36.00).
