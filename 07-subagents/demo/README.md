# Tiny Shop

A small shop backend used in our demos.

- `shop/cart.py`: the cart and its items
- `shop/pricing.py`: works out the total for a cart
- `shop/coupons.py`, `shop/rules.py`: coupon codes and discount rules
- `shop/shipping.py`, `shop/tax.py`: shipping and tax
- `shop/orders.py`, `shop/emails.py`: placing orders and order emails
- `shop/products.py`: the product catalog

Run the tests with: `python -m unittest`
